# inferguidR

Guided inference, power analysis and diagnostic accuracy in R.

This development package provides statistical procedure registries, validated
analysis specifications, reproducible results, diagnostic-accuracy tools, and
an optional Shiny interface. Unsupported or unresolved calculations report
explicit statuses. Numerical agreement with external reference programs is
not implied by repository publication.

```r
remotes::install_github("CTTIR/inferguidR")
```

See the function reference and package tests for the current interfaces.
The package is under active development and is not a certified release.
